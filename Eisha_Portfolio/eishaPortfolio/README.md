# Eisha Khan Portfolio - React Version

A modern, responsive portfolio website built with React, showcasing projects and skills as a Geospatial Analyst & GIS Developer.

## Features

- **React Router** for seamless navigation
- **Responsive Design** that works on all devices
- **Component-based Architecture** with separate files for each page
- **Modern UI/UX** with smooth animations and transitions
- **Organized Structure** with separate CSS files for each component

## Project Structure

```
eishaPortfolio/
├── public/
│   ├── images/          # Image assets
│   └── index.html       # HTML template
├── src/

│   │   ├── Header/
│   │   ├── Navigation/

│   │   ├── Home/
│   │   ├── About/

│   ├── App.css
│   ├── index.js        # Entry point
│   └── index.css       # Global styles
├── package.json
└── README.md
```

## Installation

1. Navigate to the project directory:
```bash
cd eishaPortfolio
```

2. Install dependencies:
```bash
npm install
```

## Running the Application

Start the development server:
```bash
npm start
```

The app will open at `http://localhost:3000`

## Building for Production

Create an optimized production build:
```bash
npm run build
```

## Technologies Used

- React 18.2.0
- React Router DOM 6.20.0
- HTML5 & CSS3
- Font Awesome Icons

## Pages

- **Home**: Hero section, featured projects, and skills showcase
- **About**: Personal information and technical skills
